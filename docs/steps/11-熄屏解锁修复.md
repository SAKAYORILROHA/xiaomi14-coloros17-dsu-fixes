# 步骤 11：熄屏（AOD）解锁修复

## 现象

- 亮屏锁屏下指纹正常（accept 已 34 次）
- **熄屏/ AOD 状态下按指纹区无法解锁**

## 日志给出的原因

```
KeyguardUpdateMonitor-->setFingerprintRunningState wasRunning:true,isRunning:false
  KeyguardUpdateMonitor.stopListeningForFingerprint:65
  KeyguardUpdateMonitor.updateFingerprintListeningState:97
  KeyguardUpdateMonitor.-$$Nest$mhandleDreamingStateChanged:56       ← 进入 AOD 时
```

- ColorOS 在进入 Dream（AOD）时调用 `handleDreamingStateChanged` → 重新判断 `shouldListenForFingerprint()` → 返回 false → **停止监听指纹**
- 同时 AOD 上的指纹图标被 OPlus SurfaceFlinger 隐藏（`persist.oplus.display.FingerprintHideAOD.disable` 相关逻辑），
  AOD 里没有图标可以按，也就不会触发 doze 下的认证
- 结果：熄屏时既没有图标、也没有认证会话 → 按了没反应

## 已部署的修复（fodbridge v4）

在桥接里加了「熄屏触摸 → 唤醒 + 重新触发采图」：

```
触摸落在指纹区 且 mWakefulness != Awake：
  input keyevent KEYCODE_WAKEUP      # 点亮屏幕
  sleep 0.35                          # 等 keyguard 开始监听指纹
  extCmd(4,0) + extCmd(4,1)          # 模拟一次新的"按下"，让 HAL 采图
```

效果：**熄屏下按一下指纹区就会亮屏并尝试直接解锁**；如果第一次没解开，屏幕已经亮了，再按一次（锁屏下的指纹是正常的）必定能解锁。

文件：`/data/adb/modules/fodbridge/fodbridge.sh`（= `F:\11222\module\fodbridge_v4.sh`）
日志会打印 `press x=.. y=.. (wake=Dozing -> wake screen)` / `re-triggered capture after wake`。

回滚到 v3（不唤醒）：
```
adb push F:\11222\module\fodbridge_v3.sh /data/local/tmp/f3.sh
adb shell su -c "cp /data/local/tmp/f3.sh /data/adb/modules/fodbridge/fodbridge.sh && chmod 755 /data/adb/modules/fodbridge/fodbridge.sh"
# 然后重启桥接进程
```
