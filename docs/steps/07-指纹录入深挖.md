# 步骤 07：指纹录入深挖（为什么「录入界面没有任何反应」）

## 现象复现（本次抓到的日志）

```
02:33:20 [AIDL] mfp_service: generateChallenge
02:33:22 [AIDL] mfp_service: enroll              ← HAL 收到 enroll
02:33:22 [AIDL] mfp_service: onAcquired(7) (21)  ← 然后就没有下文
02:33:31~35  FodEngineCore fingerprintConditionUpdate stateIndex:4 value:1/0   ← 桥接发的按下/抬起
             checkFodTouchStatus FP:1 gxzwAnim:1 colorfade:0 lockoutmode:0 powermode:2 TouchEnable:1
             setFodTouchCoordinatePollCtrl Need Coordinate write pipe true
             （没有 fod capture start，没有 SYS_NODE_EVENT_FINGER_DOWN）
02:33:33 [AIDL] mfp_service: Session cancel → onError(5)
```

## 与上一轮「能采图」的日志对比（F:\C17\logs\live.txt 673600 行附近）

上一轮成功时是：

```
[THP-APP]: fod_write_downup:write fod 1                   ← 触摸驱动（THP）写 /sys/class/touch/touch_dev/fod_press_status
mfp-daemon: [threadLoop] SYS_NODE_EVENT_FINGER_DOWN       ← HAL 的 threadLoop 读到 FOD 按下
mfp-daemon: setLocalHBM set local hbm:2                    ← 打开 LHBM
[GF_HAL]: sysnode touch panel detected finger down         ← 开始采图
```

关键结论：**光靠桥接发 extCmd(4) 不够**，HAL 必须收到触摸驱动（`vendor.xiaomi.hw.touchfeature-service` 里的 THP 库）写出的 `fod_press_status`，
这个「SYS_NODE_EVENT_FINGER_DOWN」才是采图触发器；坐标也是 THP 通过 pipe 送进 HAL 的。

## 为什么 THP 不写 fod_press_status

- THP 只有在该触摸 HAL 处于 `support fod=1`（`thp_daemon_cmd_process mode:10`）时，才会在手指按到 FOD 区域时写 `fod_press_status`
- ColorOS 框架不会调小米的 `setModeValue(0,10,1)`；桥接原来是在**触摸按下的同一时刻**才发 `extCmd(4)` 让 HAL 去置这个标志，
  时序上晚于 THP 处理"按下"，所以 THP 从来没机会在按键期间看到 `support fod=1`
- 上一轮能成功，是因为用户连续按了两次：第一次按下把标志置上，第二次按下时 THP 才真正写 fod

## 本次修复（fodbridge v2）

1. 找到触摸 HAL 的 AIDL 事务号：`vendor.xiaomi.hw.touchfeature.ITouchFeature/default` 的
   `setModeValue(id=0, mode=10, value=1)` = **code 9**（实测 `THP-DAE: user_cmd_set_cur_value:support fod:1`）
2. 新桥接常驻每 2 秒调用一次 code 9，让 THP 始终处于 `support fod=1`，这样**任意一次真实触摸**在 FOD 区域都会写 `fod_press_status`
3. 启动时补发 `extCmd(2,0)`（colorfade=0）和 `extCmd(3,0)`（powermode=0），与上一轮能采图时的
   `checkFodTouchStatus FP:1 gxzwAnim:1 colorfade:0 lockoutmode:0 powermode:0 TouchEnable:1` 状态对齐
4. 保留原来的 extCmd(1,1) keepalive 和 extCmd(4) 按下/抬起
