# 步骤 14：滑动变点击/长按 —— 根因是触摸 HAL 被反复切进 doze 模式（fodbridge v7）

## 定位过程

1. 先检查 THP 日志，发现 `thp_set_doze_mode_func:enable doze mode` 被**每秒反复调用**：

```
03:30:55.954 [THP-DAE]: thp_set_doze_mode_func:enable doze mode
03:30:56.696 [THP-DAE]: thp_set_doze_mode_func:enable doze mode
03:30:57.682 [THP-DAE]: thp_set_doze_mode_func:enable doze mode
...（每秒 1~2 条，持续）
```

2. 频率正好等于桥接 v6 里的 `extCmd(1,1)`（触摸控制）保活——每 1 秒一次。
   HAL 收到 `extCmd(1)` 后会通知触摸 HAL 切 doze（低功耗）模式，触摸面板在 doze 模式下**只报按下/抬起、不报移动**
   → 系统看到的就是"滑动被识别成点击/长按"。

3. 验证：停掉桥接 + 重启触摸 HAL 后，doze 模式日志立刻停止（4 秒内 0 条）。

## 修复（v7，已部署）

- **去掉 1 秒的 `extCmd(1,1)` 保活**，改成启动时一次 + 每 30 秒一次（和最初能用的 v1 一致）
- `support fod` 仍然只在**锁屏/熄屏**时开启（`dumpsys trust` → deviceLocked=1），解锁后 1~2 秒内关掉
- 指纹相关：只有锁屏时桥接才发 `extCmd(4)`；熄屏触摸仍会"唤醒 + 重新触发采图"

## 验证

```
# doze 模式刷屏应该消失
adb shell su -c "logcat -d -s THP-DAE | grep -c 'enable doze mode'"

# 锁屏状态
adb shell su -c "cat /data/local/tmp/fod.locked"
```

## 如果锁屏界面上滑仍异常

说明 `support fod=1` 也会影响锁屏手势，可以把它再限制成"只在熄屏时开启"，
锁屏亮屏时只用 `extCmd(4)` 触发（滑动 100% 恢复，代价是亮屏解锁成功率略降）。

## 回滚

```
adb shell su -c "pkill -f fodbridge.sh"     # 临时全停（模块开机才会再拉起）
```
