# 步骤 09：录入动画 / 锁屏水波纹 深挖（结论：ColorOS 图层被 OPlus SF 判为不可见）

## 现象

- 录入能成功（count=1），但录入页没有进度动画
- 录入时"打光"（LHBM 高亮）时好时坏，第一次能成，后面靠蒙
- 锁屏按压的"水波纹"动画看不到

## 已修复：打光可靠性（fodbridge v3）

原因：小米 HAL 在 `extCmd(4,0)`（抬手）时会把触摸 HAL 的 `mode:10`（support fod）关掉，
而原来的常驻补发是每 2 秒一次 → 如果两次按压间隔 <2s，THP 在按下时 `support fod=0`，
就不会写 `fod_press_status`，HAL 也就不采图/不打光 → "靠蒙"。

v3 改动：
- 每次抬手 `extCmd(4,0)` 后**立刻**补发 `setModeValue(0,10,1)`（tanghfeature AIDL code 9）
- 按下时先补一次再发 `extCmd(4,1)`
- 保活周期从 2s 缩到 1s

文件：`F:\11222\module\fodbridge_v3.sh`（已部署到 `/data/adb/modules/fodbridge/fodbridge.sh` 并重启）

## 未解决：动画本身渲染不出来（实测证据）

1. 动画资源确实加载了：

```
OnScreenFingerprintUiMech-->getOptions ANIM_TYPE_PRESSED, drawableName:kgd_fingerprint_element_60fps, drawableFrames:26
VFX:COELoader: load assetFile:WaterRippleAnimation.coz
tryToScalePressedAnim: mPressedAnimScaleRate 1.357 -> 0.8
```

2. 但 SurfaceFlinger 里这几个图层根本没被画出来：

```
Layer OnScreenFingerprintPressedIcon
  invisible reason=oplusIsVisible{false,fingerPrint @432}
  geomCrop=[0 0 -1 -1]        ← 空裁剪，整层不画
Layer OnScreenFingerprintDimLayer
  geomCrop=[0 0 -1 -1]        ← 同上
Layer OnScreenFingerprintIcon
  visible reason= buffer=...  ← 只有图标层是可见的
```

3. 对按压前后的截图做像素差分：图标区域（y=2316~2495, x=510~689）**0 像素变化**，
   说明按下/波纹/进度这些 UDFPS 图层完全没有合成到屏幕上。

结论：这是 ColorOS 的 OPlus SurfaceFlinger 可见性控制（`oplusIsVisible`）+ COE/VFX 动画链路
在小米硬件/移植环境下的缺失，**不是设置能开关的**；要修必须改 SystemUI（或它的 SF/显示 HAL 依赖）。
