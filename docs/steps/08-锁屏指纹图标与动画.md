# 步骤 08：锁屏指纹图标 / 识别动画 / 录入进度 修复

## 现象

- 录入成功（`dumpsys fingerprint` → `count=1`），但**锁屏不显示指纹图标**，没法按指纹解锁
- 锁屏指纹识别（按下）**没有动画**
- 录入界面**不显示进度**

## 根因（SystemUI 的 haveFp() 门控）

ColorOS 的锁屏指纹图标/动画/进度都由 SystemUI 的 `OplusKeyguardStyleBaseUIControllerImpl.haveFp()` 决定：

```
haveFp() = KeyguardFeatureOption.isSupportUdfps() && FingerSwitchHelper.isFingerprintUnlockEnable()
```

- `isSupportUdfps()` 读 `persist.vendor.fingerprint.sensor_type=optical` → true
- `isFingerprintUnlockEnable()` 读 **secure 设置 `oplus_customize_fingerprint_unlock_switch`**
  （`FingerSwitchHelper.mFingerprintUnlockEnabled`，由 `mSideFpUnlockModeObserver` 监听这个键）
- 本机这个键是 **null** → false → `haveFp()` false
- 于是 `initFpInfo()` 把 `global fingerprint_icon_info` 写成 `fpIconShouldShowOnKeyguard=0`，
  锁屏不画指纹图标，同时 UDFPS 的按压动画/录入进度也被关掉

实测日志（修复前）：

```
initFpInfo fpIconShouldShowOnKeyguard=0,fpIconSize=179,fpDownMarginBottomStatic=174
BottomAffordanceContainer-->... fpIconVisible=false
UdfpsController: Null request when onAcquired ...
```

## 修复（已执行）

```
settings put secure oplus_customize_fingerprint_unlock_switch 1
settings put secure oplus_customize_fingerprint_unlock_enter_desktop 1
settings put secure fingerprint_enabled 1
```

立刻生效（SystemUI 有 ContentObserver，无需重启）：

```
FingerSwitchHelper-->isFingerprintSwitchOn = true , state = 1
OplusKeyguardStyleBaseUIController-->initFpInfo fpIconShouldShowOnKeyguard=1
global fingerprint_icon_info = {"fpIconShouldShowOnKeyguard":1,...}
```

## 仍未解决：AOD（熄屏）上的指纹图标

- 全屏 AOD 已经常亮（背光 279），但 AOD 画面上**没有**指纹图标（像素对比 y2300~2520 区域与录入前完全一致）
- 原因：AOD 的指纹图标由 `OnScreenFingerprintUiMech`（UDFPS 窗口）在 doze 里显示，
  而 `OnScreenFingerprintUiMech.onScreenTurnedOff()` 会把窗口隐藏（`isOnScreen=false, mDrawState=NO_SURFACE`），
  AOD 侧还依赖 `AODDisplayUtil.isFpDelayUntilDozeAodProcessType()`（OPlus 面板 feature，Xiaomi 硬件上不存在）
- 这条路要改 SystemUI（工作区已有上一轮做的 `系统界面_强制AOD全屏.apk` 补丁），需要另行验证签名能否安装
