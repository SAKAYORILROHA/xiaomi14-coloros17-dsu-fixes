# 指纹修复 v8（powermode 导致不采图）

> 设备：Xiaomi 14（houji）+ ColorOS 17 移植版（DSU）
> 时间：2026-10-21 05:29
> 现象：进了"添加指纹"界面，按指纹区没反应 / 不打光 / 录不进去

---

## 一、日志抓到的根因

桥接已经能发 `extCmd(4)`，但 mfp-daemon 的采图条件里 `powermode` 是 **2**：

```
05:27:56.740 D/mfp-daemon: FodEngineCore fingerprintConditionUpdate stateIndex:4 value:1
05:27:56.740 D/mfp-daemon: checkFodTouchStatus FP:1 gxzwAnim:1 colorfade:0 lockoutmode:0 powermode:2 TouchEnable:1
05:27:56.751 D/mfp-daemon: setFodTouchCoordinatePollCtrl Need Coordinate write pipe true
05:27:56.864 D/mfp-daemon: setLocalHBM set local hbm:1          ← 只关灯，没有采图
05:27:56.864 D/mfp-daemon: HandleFodTouchCtl:0
```

对照正常采图时应该是：

```
checkFodTouchStatus FP:1 gxzwAnim:1 colorfade:0 lockoutmode:0 powermode:0 TouchEnable:1
```

`powermode` 由 HAL 的 `extCmd(3, x)` 控制，框架/息屏会把它置成 2；旧的 v1 桥接只在启动时发过一次 `extCmd(1,1)`，**从来没发过 `extCmd(2,0)/extCmd(3,0)`**，所以屏幕上一直是 powermode=2 → 不采图、不打光。

手动验证：

```
service call ...IXiaomiFingerprint/default 1 i32 3 i32 0
→ checkFodTouchStatus FP:0 gxzwAnim:1 colorfade:0 lockoutmode:0 powermode:0 TouchEnable:1
```

powermode 立刻变成 0。

## 二、修复内容（v8）

`fodbridge.sh` 在 v1（触摸安全的最小集合）基础上补两件事：

| 时机 | 动作 |
|---|---|
| 启动时 | `extCmd(2,0)` colorfade=0、`extCmd(3,0)` powermode=0、`extCmd(1,1)` 触摸控制 |
| 每次指纹区按压 | 先补 `extCmd(2,0)` + `extCmd(3,0)`，再 `extCmd(4,1)`；抬手 `extCmd(4,0)` |
| 息屏按压 | `KEYCODE_WAKEUP` 点亮 → `extCmd(3,0)` → `extCmd(4,0)`+`extCmd(4,1)` 重新触发采图 |
| 保活 | `extCmd(1,1)` 每 **30 秒**一次（不是 1 秒！1 秒一次会让触摸面板反复进 doze，滑动变点击） |

**依然不做**：
- 不常驻 `support fod`（`setModeValue(0,10,1)`）——常驻会让触摸只剩"点击/长按"、不能滑动
- 不做 1 秒一次的 `extCmd(1,1)`

## 三、安装 / 更新

```bash
# 把整个目录推到手机
adb push 指纹修复_v8 /data/local/tmp/dsufix_fp_v8
adb shell su -c "sh /data/local/tmp/dsufix_fp_v8/deploy.sh /data/local/tmp/dsufix_fp_v8"
```

脚本会：拷贝到 `/data/adb/modules/fodbridge/` → 杀掉旧桥接 → 用 setsid 重新拉起 → 打印进程和日志。

验证：

```bash
adb shell su -c "tail -6 /data/local/tmp/fodbridge.log"
adb shell su -c "logcat -d -b all -v time | grep checkFodTouchStatus | tail -3"
```

期望：`powermode:0`；按压时出现 `SYS_NODE_EVENT_FINGER_DOWN` → `setLocalHBM set local hbm:2` → `fod high brightness capture start`。

## 四、录入 / 解锁要点

1. 设置 → 指纹 → 添加指纹，忽略界面上"转圈滑动/触摸电源键"的文案（移植 ROM 的侧边指纹文案 Bug）
2. 用指腹**按住屏幕底部正中约 2 秒**，听到提示再抬起；同一个位置重复 2~3 次
3. 解锁时**每次按完等 2~3 秒**再按（HAL 采图有重试节流）
4. 同一根手指可以多录 1~2 枚，HAL 取最佳匹配

---

## 五、仍然存在的限制

- 指纹按压/录入动画、AOD 上的指纹图标不显示：ColorOS 的 UDFPS 图层被 OPlus SurfaceFlinger 判成
  `invisible reason=oplusIsVisible{false,fingerPrint}` + 空裁剪（需要改 SystemUI 或重启 SF）
- 识别率偏低（`image_quality` 20~25、`match_score` 56~58 卡阈值）：缺少"采图压暗 + 局部高亮"链路
